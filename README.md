# YesPlease
v1.60.1a

One-click or automatic confirmation of StaticPopup dialogs in World of Warcraft Forever (Interface 16001).

## Features
- `/yes` — Instantly click the first visible confirmation button.
- Optional auto-confirm for a large whitelist of common dialogs (enchants, poisons, AH buyouts, group invites, binds, etc.). Some are enabled by default.
- Minimap button + settings window with checkboxes for every option in the whitelist.

## Installation
1. Extract the `YesPlease` folder into:
`World of Warcraft/_forever_/Interface/AddOns/`

2. Reload WoW.

## Usage
- Click the minimap button or type `/yp` to open the settings panel.
- Toggle individual dialogs on/off.
- `/yes` still works as a manual one-click confirm anytime. Can be used in your own macro.
- `/yp auto` / `/yp auto off` for the master switch.
- `/yp list` to print the current whitelist.
